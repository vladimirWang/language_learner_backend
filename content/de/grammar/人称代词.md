# 人称代词（Personalpronomen）

## 概述

人称代词指代人或事物，随句子成分变化格：第一格作主语，第四格作直接宾语，第三格作间接宾语。第二格在 A2-B1 阶段以了解为主。

> 各格标准答案以真值库 `grammar_forms` 为准，本文件仅用于讲解与辨析。

## 第一格（Nominativ，主语）

| 人称 | 形式 | 含义 |
|---|---|---|
| 1sg | ich | 我 |
| 2sg | du | 你 |
| 3sg m | er | 他 |
| 3sg f | sie | 她 |
| 3sg n | es | 它 |
| 1pl | wir | 我们 |
| 2pl | ihr | 你们 |
| 3pl | sie | 他们 / 她们 |
| 尊称 | Sie | 您 / 各位 |

## 第四格（Akkusativ，直接宾语）

| 人称 | 形式 |
|---|---|
| ich | mich |
| du | dich |
| er | ihn |
| sie | sie |
| es | es |
| wir | uns |
| ihr | euch |
| sie | sie |
| Sie | Sie |

例句：Ich sehe dich.（我看见你。）/ Ich kenne ihn.（我认识他。）

## 第三格（Dativ，间接宾语）

| 人称 | 形式 |
|---|---|
| ich | mir |
| du | dir |
| er | ihm |
| sie | ihr |
| es | ihm |
| wir | uns |
| ihr | euch |
| sie | ihnen |
| Sie | Ihnen |

例句：Er hilft mir.（他帮助我。）/ Ich gebe ihm das Buch.（我把书给他。）

## 第二格（Genitiv，B1 了解）

meiner、deiner、seiner、ihrer、seiner、unser、euer、ihrer、Ihrer；多用于书面所属表达，口语常被 `von + Dativ` 替代。

## 双宾语顺序：人三物四

同时出现间接宾语（人）与直接宾语（物）时，书面优先第三格在前、第四格在后：

- ✅ Ich gebe dir das Buch.（我把这本书给你。）
- 直接宾语为代词时，代词第四格置于第三格之前：Ich gebe es dir.

## 易混点

- `sie` 小写：她（单数）/ 他们、她们（复数）；`Sie` 大写：尊称「您」，永远大写，变位按复数处理。
- `er` / `sie` / `es` 除指代人外，也按名词词性指代事物，不对应自然性别。
