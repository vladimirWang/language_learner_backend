# 第二分词（Partizip II）构成规则

## 用途

第二分词用于构成现在完成时（Perfekt）与被动语态，是完成时句子中的核心形式。

## 弱变化动词（规则）

`ge-` + 词干 + `-t`：

- machen → gemacht；lernen → gelernt；wohnen → gewohnt；kaufen → gekauft。

## 强变化动词（不规则）

`ge-` + 变化词干 + `-en`：

- sehen → gesehen；gehen → gegangen；essen → gegessen；schreiben → geschrieben；trinken → getrunken。

## 可分动词

`ge-` 插在可分前缀与词干之间：

- aufstehen → aufgestanden；einkaufen → eingekauft；mitmachen → mitgemacht。

## 不可分动词

前缀 `ver-、be-、er-、ent-、zer-、ge-` 等不可分，**不加 `ge-`**：

- verstehen → verstanden；besuchen → besucht；erklären → erklärt；entstehen → entstanden。

## 特殊动词：sein / haben

- sein → gewesen；haben → gehabt。

## 完成时助动词选择

- **sein**：不及物动词表示位移或状态变化，如 gehen、kommen、fahren、aufstehen、sterben。
- **haben**：及物动词，以及不表示位移 / 状态变化的不及物动词，如 machen、lesen、haben、wohnen。

## 考点提醒

- 第二分词在完成时中置于句末；从句中位于变位助动词之前。
- 不规则分词形式需逐词记忆，标准答案以真值库为准。
