# 第二虚拟式（Konjunktiv II）

## 用途

第二虚拟式表达非现实假设、愿望，以及委婉客气的请求或询问。

## 构成方式

1. **弱变化动词**：第二虚拟式与过去时形式相同，通过上下文区分。
2. **强变化动词**：在过去时词干基础上变音（ä / ö / ü）+ 虚拟式人称词尾。
3. **高频特殊形式**：
   - sein → wäre；haben → hätte；können → könnte；wollen → wollte；müssen → müsste；sollen → sollte。

## 核心句型：非现实条件

- Wenn ich Zeit hätte, würde ich kommen.（如果我有时间，我就来。）—— 现实是我没时间。
- Wenn er mehr lernen würde, bestünde er die Prüfung.（他要是多学些，就能通过考试。）

## würde + 动词原形（B1 主流写法）

口语与书面中大量使用 `würde + Infinitiv` 简化虚拟式变位，避免生硬的强变化虚拟式：

- Wenn ich Zeit hätte, würde ich Deutsch lernen.（如果我有时间，我就学德语。）
- Ich würde gern einen Kaffee trinken.（我想喝杯咖啡。）

## 礼貌用法

- Könnte ich bitte das Fenster öffnen?（我可以打开窗户吗？）—— 比 `kann` 更委婉。
- Ich hätte gern eine Tasse Tee.（我想要一杯茶。）

## 考点提醒

- 第二虚拟式不表示真实发生，翻译时常带「本来 / 要是 / 就会」。
- `wäre` / `hätte` 与 `würde + 原形` 的选择：高频动词用虚拟式特殊形式，其余多用 `würde` 结构。
- 具体变位标准答案以真值库 `grammar_forms` 为准。
