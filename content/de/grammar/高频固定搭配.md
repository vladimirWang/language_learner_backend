# 德语高频固定搭配（A2-B1）

## 说明

本文件收录动词 / 形容词 / 名词与介词的固定支配搭配。搭配所要求的格属于固定真值，应录入结构化 CSV 供出题与批改查表；本文件仅用于讲解、记忆与辨析。

## 动词 + 介词

| 搭配 | 介词 + 格 | 含义 | 例句 |
|---|---|---|---|
| warten auf +A | auf + 第四格 | 等待…… | Ich warte auf den Bus. |
| denken an +A | an + 第四格 | 想到…… | Ich denke an dich. |
| träumen von +D | von + 第三格 | 梦见 / 梦想…… | Er träumt von einer Reise. |
| sich freuen auf +A | auf + 第四格 | 期待…… | Wir freuen uns auf den Urlaub. |
| sich freuen über +A | über + 第四格 | 为……感到高兴 | Sie freut sich über das Geschenk. |
| Angst haben vor +D | vor + 第三格 | 害怕…… | Er hat Angst vor dem Hund. |
| Interesse haben an +D | an + 第三格 | 对……感兴趣 | Sie hat Interesse an der Geschichte. |
| teilnehmen an +D | an + 第三格 | 参加…… | Er nimmt an dem Kurs teil. |
| sich erinnern an +A | an + 第四格 | 回忆起…… | Ich erinnere mich an den Tag. |
| sich vorbereiten auf +A | auf + 第四格 | 为……做准备 | Wir bereiten uns auf die Prüfung vor. |

## 形容词 + 介词

| 搭配 | 介词 + 格 | 含义 |
|---|---|---|
| wichtig für +A | für + 第四格 | 对……重要 |
| gut in +D | in + 第三格 | 擅长…… |
| zufrieden mit +D | mit + 第三格 | 对……满意 |
| interessiert an +D | an + 第三格 | 对……感兴趣 |
| bereit für +A | für + 第四格 | 准备好…… |
| fertig mit +D | mit + 第三格 | 做完…… |

## 名词固定搭配

- Lust haben auf +A 想要……（Ich habe Lust auf einen Spaziergang.）
- Zeit haben für +A 有时间做……
- Hunger haben nach +D 想吃……；Durst haben nach +D 想喝……
- Angst vor +D 对……的恐惧；Freude an +D 对……的乐趣

## 使用注意

1. 同一动词搭配不同介词时含义不同，如 sich freuen auf（期待未来）与 sich freuen über（为已发生之事高兴）。
2. 介词与格的搭配固定，不因句子时态改变。
3. 新增搭配统一录入真值库，避免模型凭印象生成介词。
