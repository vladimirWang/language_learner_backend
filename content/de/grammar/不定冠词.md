# 不定冠词（unbestimmter Artikel）ein

## 基础说明

不定冠词对应英语 a / an，只用于单数可数名词；复数前没有不定冠词（零冠词）。词干 `ein` 随后面名词的性与格变化。

> 变格标准答案以真值库为准，本文件仅讲解用法。

## 第一格（Nominativ）

| 性 | 形式 | 示例 |
|---|---|---|
| 阳性 m | ein | ein Hund |
| 阴性 f | eine | eine Katze |
| 中性 n | ein | ein Buch |

例句：Das ist ein Hund.（这是一只狗。）

## 第四格（Akkusativ）

| 性 | 形式 | 示例 |
|---|---|---|
| 阳性 m | einen | einen Hund |
| 阴性 f | eine | eine Katze |
| 中性 n | ein | ein Buch |

例句：Ich sehe einen Hund.（我看见一只狗。）

## 第三格（Dativ）

| 性 | 形式 | 示例 |
|---|---|---|
| 阳性 m | einem | einem Kind |
| 阴性 f | einer | einer Frau |
| 中性 n | einem | einem Kind |

例句：Ich helfe einem Kind.（我帮助一个孩子。）

## 第二格（Genitiv，B1）

eines（m / n）、einer（f），如 das Haus eines Mannes（一个男人的房子）。

## 重点考点

1. 复数名词前不用 `ein`，直接零冠词。
2. 否定冠词 `kein` 的变格规则与 `ein` 完全一致。
3. 不定冠词无第二格复数形式，复数所属用 `von + Dativ`。
