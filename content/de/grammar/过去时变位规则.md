# 过去时（Präteritum）变位规则

## 使用场景

过去时多用于书面叙事、小说、新闻；日常口语对话中更常用现在完成时（Perfekt）。`sein、haben` 以及情态动词的过去时在口语中也很常见。

## 弱变化动词（规则动词）

词干 + `-te` + 人称词尾：

- machen → machte：ich machte、du machtest、er/sie/es machte、wir machten、ihr machtet、sie/Sie machten。
- lernen → lernte；arbeiten → arbeitete。

## 强变化动词（不规则动词）

词干元音发生变化，不加 `-te`，直接接人称词尾：

- gehen → ging；sehen → sah；essen → aß；trinken → trank；schreiben → schrieb。

## 高频特殊动词：sein / haben

- **sein**：ich war、du warst、er/sie/es war、wir waren、ihr wart、sie/Sie waren。
- **haben**：ich hatte、du hattest、er/sie/es hatte、wir hatten、ihr hattet、sie/Sie hatten。

## 易混提醒

- 不要把过去时（Präteritum）与现在完成时（Perfekt：`haben / sein + 第二分词`）混淆。
- 强变化动词的词干变化需逐词记忆，标准答案以真值库 `grammar_forms` 为准。
- 过去时否定用 `nicht`，位置随句子成分而定。
