# help

## 释义

help 作动词表示「帮助」，可作及物或不及物动词：help sb. / help with sth.

## 变形

- 第三人称单数：helps
- 过去式：helped
- 过去分词：helped
- 现在分词：helping

## 搭配

- help sb. with sth.：在某事上帮助某人
- help sb. do sth.：帮助某人做某事
- cannot help doing sth.：忍不住做某事

## 例句

- She helps me with my homework. 她帮我做作业。
- Can you help me carry this box? 你能帮我搬这个箱子吗？

## 易混辨析

- help 后接动词原形（help sb. do），不是不定式 to do。
